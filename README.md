## **Object Detection For Traffic**

### **Project Overview**

This project demonstrates the application of the YOLO object detection model for traffic-related object detection using the Ultralytics framework. The notebook is built upon the COCO dataset and is capable of detecting common objects in both images and videos. The primary goal is to apply computer vision in real-world scenarios to enable human-like visual automation. In this project, I also experimented with public traffic data from Hong Kong.

### **Key Features**

- **Model Training**: Utilizes the Ultralytics YOLO framework to train models for object detection tasks.  
- **Real-Time Detection**: Performs real-time object detection on video streams or individual images to identify traffic-related objects (e.g., cars, buses, trucks, etc.).  
- **Customization**: Supports custom datasets and fine-tuning for domain-specific applications like traffic monitoring.

YOLO Official: https://docs.ultralytics.com
